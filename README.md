# Bach Challenge Project

This repository includes all Jupyter notebooks for preliminary experiments, all source code used to run those and a final report.

## Repository Structure

The project is organised as follows:

- **`final_report/`**: Includes the final submission notebook (`submission.ipynb`) and images for the final analysis.
- **`preliminary_experiments/`**: Contains Jupyter notebooks used for initial experiments and hyperparameter tuning.
- **`src/`**: Contains all the source code modules used for training, evaluation, and data processing.

## Experiments Overview

The preliminary experiments are documented in the following notebooks:

- **`run1.ipynb`**: Covers **Data Augmentation** experiments.
- **`run2.ipynb`**: Covers **Resolution** experiments.
- **`run3.ipynb`**: Covers **Learning Rate** experiments.
- **`run_ensemble.ipynb`**: Contains the final ensemble run that produces the final results.

> **Note**: The file paths in the preliminary experiment notebooks may not be up to date, as files were moved from my old repository structure for a more intuitive submission directory structure.
